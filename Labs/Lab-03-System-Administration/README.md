# Lab 03 - Linux System Administration

## Objective
Develop foundational system monitoring and
process management skills.

## Environment
- Ubuntu Linux ARM64
- UTM Virtual Machine

## Practical Exercises
- Inspected running processes.
- Compared static and real-time process monitoring.
- Identified active desktop processes.
- Examined filesystem storage utilization.

## Commands Used
- ps aux
- top
- df -h

## Findings
- ps aux provides a snapshot of running processes.
- top continuously updates process information.
- df -h displays human-readable filesystem usage.
- Identified gnome-shell and ptyxis processes.

## Skills Developed
- Process analysis
- System monitoring
- Resource management
- System diagnostics

## Status
Documented exercises completed.
