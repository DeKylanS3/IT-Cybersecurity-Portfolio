# Lab 02 - Linux Fundamentals and Access Control

## Objective
Develop Linux command-line proficiency and foundational
filesystem and user administration skills.

## Environment
- Ubuntu Linux ARM64
- UTM Virtual Machine
- Bash Shell

## Practical Exercises
- Filesystem navigation
- File and directory creation
- File ownership and permissions
- User account management
- Access control
- Permission troubleshooting

## Commands Studied
- pwd
- ls
- cd
- mkdir
- touch
- cat
- cp
- mv
- rm
- chmod
- chown
- adduser
- id

## Security Concepts
- Principle of least privilege
- Authentication and authorization
- User and group permissions
- File ownership

## Skills Developed
- Linux command-line navigation
- Filesystem management
- Access control fundamentals
- Technical troubleshooting
